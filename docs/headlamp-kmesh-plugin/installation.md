# Installation

## Via Headlamp Plugin Catalog (Desktop)

1. Navigate to **Plugin Catalog** in Headlamp Desktop.
2. Search for **Kmesh** and click **Install**.
3. Click **Reload UI** to activate the Kmesh sidebar section.

## From Source

```bash
git clone https://github.com/headlamp-k8s/plugins
cd plugins/kmesh
npm install
npm run build
```
